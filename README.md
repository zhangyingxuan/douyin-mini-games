# 别惹我的刀 v0.5.0

AppID：`tt2d5d5be0b32324e702`。独立编写的抖音原生 Canvas 试玩工程，无需安装依赖、无需构建，不含原作代码、美术与角色。西游角色采用 AI 生成的独立设计图集。

## 浏览器试玩

在本目录运行 `npm run preview`，打开 http://127.0.0.1:4173 。需要 Node.js 18+。拖动移动，电脑也支持 WASD / 方向键，Escape 暂停。竖屏体验最佳；窗口尺寸变化后刷新。

## 导入抖音开发者工具

1. 选择导入「小游戏」，目录选择本项目根目录。
2. 确认 AppID、入口 `game.js` 和竖屏配置。
3. 先编译预览，再用绑定开发者身份的抖音账号扫码测试。
4. 验证拖动、后台暂停、三选一升级、精英耗刀、死亡重开、纪录保存。

如工具要求重新生成工程配置，保留 AppID、小游戏类型及入口。

## 玩法

开局6把飞刀、7点生命，前期小怪一击击败。升级必定增加1把刀上限、补满刀并恢复1点生命，再三选一强化；60秒后可能生成带刀精英，对刀双方耗刀，精英无刀逃跑。每0.8秒补1把刀；首关生存90秒胜利，生命归零失败。增加命中击退、伤害飘字、刀光与3秒连斩反馈。

## 验证

运行 `npm test` 检查移动、成长、碰撞、刀阵对抗、死亡及胜利。

## 西游角色资源

`assets/journey-characters.png` 为透明四宫格图集：左上孙悟空、右上狼妖、左下野猪妖、右下牛魔王。运行时使用 Canvas 裁切绘制，不需要切图工具。小妖与精英保持原有碰撞体和数值，仅更新外观。

图片通过 `tt.createImage()` 加载，失败时保留简易形象；成功会输出 `blade:atlas ready` 日志。浏览器预览服务也公开此图集。当前使用立绘浮动表现，没有逐帧走路动画。

## 地图与神通界面

`assets/huaguo-ground.png` 为生成的花果山地表图，按世界坐标平铺滚动；草木和石头仅作装饰，不设碰撞。`blade:ground ready` 表示加载完成。地图失败时使用纯色背景，保证可继续战斗。

神通选择采用玉色鎏金卡片，展示图标、类别、名称与效果；整张卡片都是点击区域。卡片高度随视口调整，支持剩余两项强化时居中显示。

## 音效

九个原创合成短音效位于 `assets/audio/`，由 `python tools/generate_audio.py` 可重复生成，无外部采样、旋律或第三方音效依赖。命中、击败、拾取、受伤采用轻量提示，升级与结算采用短音阶；没有循环背景音乐。

首次触摸后启用，音量为40%，遵循系统静音开关；左下角音效开关会保存。暂停或切后台立即停止。共用一个声道并对密集事件限频，优先播放升级、受伤和结算提示；资源或设备播放失败时不阻断游戏。

发布前需用安卓/iOS真机试听，按手机扬声器和耳机实际表现调整音量。
